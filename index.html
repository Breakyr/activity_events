jQuery Selectors Used

$("#changeTextButton")
I used this id selector to grab the Click Me button. When that button is clicked, jQuery changes the paragraph text and highlights it.
$(".hoverBox")
I used this class selector for the paragraph that says to hover over it. When the mouse goes over it, jQuery adds a style to change how the paragraph looks.
$(".hideButton")
I used this class selector for the double-click button. When it is double-clicked, jQuery hides that same button from the page.
$("#nameInput")
I used this id selector for the text box. The keypress event runs when a key is pressed, so the page shows a message while someone is typing.
